# Holberton School — Modern AI

Projects for the Holberton School Modern AI curriculum.

## Projects

- [Data Analysis](data_analysis/)
  - [Data Preparation and Visualization](data_analysis/data_preparation_visualization/) —
    exploring, cleaning, and visualizing the Telco Customer Churn dataset
    with `pandas`, `matplotlib`, and `seaborn`
  - [Web Scraping](data_analysis/web_scraping/)

## Requirements

- Ubuntu 20.04 LTS, Python 3.11
- All Python files start with `#!/usr/bin/env python3`, end with a new line,
  and are executable
- Code follows `pycodestyle`
- All modules, classes, and functions are documented
